## Scale

Use a **1-4 scale** for each criterion:

- `1` = Poor
- `2` = Fair
- `3` = Good
- `4` = Excellent

## Criteria

### 1. Writing Quality

Is the response easy to read and efficiently structured?

- `1`: provides no rationale at all, or is hard to follow because of rambling, disorganization, or awkward phrasing
- `2`: understandable, but noticeably wordy, repetitive, or clunky
- `3`: clear and easy to follow, but still somewhat wordy, uneven, or less efficiently structured
- `4`: very clear, well-structured, concise, and easy to scan, with no noticeable writing issues

### 2. Evidence Use

Does the response justify its answer using details from the prompt?

- `1`: answer is mostly asserted, with little or no real prompt-based support
- `2`: some prompt evidence is used, but the justification is weak, generic, or incomplete
- `3`: the main answer is supported by prompt details, with only minor gaps
- `4`: the answer is directly justified using strong, specific prompt evidence

### 3. CTI Concept Use

Does the response use the right CTI concepts correctly to support its answer?

- `1`: uses no relevant CTI concepts, or uses CTI concepts not relevant to the question
- `2`: uses some relevant CTI concepts, but with important mistakes or vague distinctions
- `3`: mostly uses the right CTI concepts correctly, with minor imprecision
- `4`: uses the right CTI concepts precisely and consistently to support the answer
